Introduction

A spreadsheet tool for organising and understanding data

Microsoft Excel is a popular spreadsheet application developed by Microsoft. It is used to store, organise, calculate and analyse data in a tabular format. Information is arranged in rows and columns, and each box formed where a row and column meet is called a cell.

Excel is useful because it combines an easy-to-use grid with functions that can perform calculations and work with text. It can also create graphs and charts to help present information clearly.

What Excel helps us do

  • Store: keep information in a table.
  • Organise: arrange data in rows and columns.
  • Calculate: perform mathematical operations quickly.
  • Analyse: use data to create graphs and charts.
Rows, columns and cells

A row runs horizontally, a column runs vertically, and a cell is the box at their intersection. For example, C3 means the cell in column C and row 3.

Part 01

What are functions in Excel?

Functions are pre-defined formulas in Excel. They help perform simple as well as complex calculations. A function can accept arguments (the values or inputs supplied to it) and return a result.

Every function begins with an equal-to sign (=), followed by the function name and its arguments inside parentheses.

Anatomy of a function

=SUM(6,9971)
The = is the compulsory equal-to sign, SUM is the function name, and (6,9971) contains the arguments. The output is 9977.

General syntax

=FUNCTION(arguments)

Functions can perform arithmetic, trigonometric and logical calculations, and they can also work with text entries. This project groups examples into two categories:

  • Text functions: work with text entries, such as extracting characters or changing letter case.
  • Numerical functions: perform operations on numbers, such as addition, averaging and rounding.
Part 02

Text functions in Excel

Text functions help us extract, count, join, format and change text. The examples below use the word “COMPUTER”, simple words and numbers to show what each function returns.

FunctionPurposeExampleOutput
LEFT(text, [num_chars])Extracts characters from the left side.=LEFT("COMPUTER",4)COMP
RIGHT(text, [num_chars])Extracts characters from the right side.=RIGHT("COMPUTER",4)UTER
MID(text, start_num, num_chars)Extracts characters from the middle.=MID("COMPUTER",3,4)MPUT
LEN(text)Counts the number of characters.=LEN("Excel")5
UPPER(text)Converts text to uppercase.=UPPER("excel")EXCEL
LOWER(text)Converts text to lowercase.=LOWER("EXCEL")excel
PROPER(text)Capitalises the first letter of each word.=PROPER("microsoft excel")Microsoft Excel
TRIM(text)Removes extra spaces from text.=TRIM(" Hello World ")Hello World
CONCAT(text1, [text2], ...)Joins two or more text strings.=CONCAT("Hello"," World")Hello World
TEXT(value, format_text)Converts a number into formatted text.=TEXT(1234.5,"0.00")1234.50
Quick way to remember

LEFT, RIGHT and MID extract parts of text; LEN counts characters; UPPER, LOWER and PROPER change letter case; and CONCAT joins text.

Part 03

Numerical functions in Excel

Numerical functions perform calculations on numbers. They can add values, find averages, identify the highest or lowest number, count numeric entries and carry out other mathematical operations.

FunctionPurposeExampleOutput
SUM(number1, [number2], ...)Adds numbers together.=SUM(10,20,30)60
AVERAGE(number1, [number2], ...)Calculates the average.=AVERAGE(10,20,30)20
MAX(number1, [number2], ...)Finds the largest value.=MAX(10,25,15)25
MIN(number1, [number2], ...)Finds the smallest value.=MIN(10,25,15)10
COUNT(value1, [value2], ...)Counts cells containing numbers.=COUNT(10,20,30)3
PRODUCT(number1, [number2], ...)Multiplies numbers together.=PRODUCT(5,4)20
ROUND(number, num_digits)Rounds a number to specified digits.=ROUND(12.567,2)12.57
ABS(number)Returns the absolute value.=ABS(-25)25
SQRT(number)Calculates the square root.=SQRT(64)8
POWER(number, power)Raises a number to a specified power.=POWER(5,2)25

For example, =SUM(10,20,30) adds the three values and returns 60. =AVERAGE(10,20,30) returns 20, while =MAX(10,25,15) and =MIN(10,25,15) find the highest and lowest values.

Conclusion

Making data easier to work with

Microsoft Excel combines the spreadsheet grid with functions that make it easier to organise and work with information. Text functions help handle words and characters, while numerical functions help perform calculations on values.

Understanding the syntax of a function and choosing the right function for a task are useful first steps towards working confidently with spreadsheets.
